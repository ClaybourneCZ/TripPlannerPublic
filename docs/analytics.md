# Application for trip planning

## Goals of this application

This application allows you plan trip easily and export the information about trip in `pdf` format.

Or export the route to various maps like `Google maps`, `mapy.com`, `Apple maps` etc.

Allows you to create a informational group to invite your friends and plan together. 

Also allows you to access information about interesting places the given area with the help of `Informační centrum`.

## User usage

This part explains basic use-cases in application


- register as new user

- login as returning user

- logoff as current user

- as non **resgistered** 
    - access to only one trip, which **won't be** saved for next time
    - user will be able to export the trip, and upload it back when he visits application again

- as **registered** 
    - unlimited number of trips, which are saved for export and/or share with the others
    - user will be able to export the trip
    - share it with friends
    - modify users personal data    
    - create groups for more users
    - join/leave group
    - chat with other users in group

- view map
    - select places and add them as parts of some trip
    - view interesting places around picked points
    - display interesting destinations
    - view path of selected trip
    - via click visit sites like `Informační centrum` or other for reviews of the clicked place

- plan trip
    - add trip details
    - view current path of the trip
    - show some statistics about trip
    - add more people that will be part of the trip
    - **export the trip to maps** like `Google maps`, `mapy.com`, `Apple maps`
